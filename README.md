# Actividad 2

En este repositorio desarrollaré la Actividad 2 del curso electivo Introducción a la Ciencia de los Datos.

El objetivo es practicar el uso de Git y GitHub mediante la creación, modificación y documentación de archivos de texto (.txt).

El trabajo se realizará de manera individual, utilizando comandos básicos de Git y mensajes de confirmación claros y descriptivos.
